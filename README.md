# Software Engineering & AI/ML Journey

I'm a Computer Science student at Busitema University in Uganda.  
I'm building real software engineering skills step by step — starting with Python and SQL, then moving into backend development, and later into machine learning and AI systems.

The goal is not just to finish projects. I want to actually understand what I'm building, test it properly, explain my decisions, and be able to improve or rebuild it on my own.

## How I'm approaching this

For every project or learning phase:

1. Understand what needs to be done
2. Break it into smaller parts
3. Try to implement it myself first
4. Test normal cases, edge cases, and invalid inputs
5. Debug and fix problems
6. Think about better ways to structure the code
7. Write down the important decisions I made
8. Practise variations of the same problem
9. Document the useful parts
10. Only move forward when I can show that I understand it

I use AI tools to help me understand concepts, debug, and generate test ideas. But I take responsibility for verifying everything and making sure I actually understand the final code.
